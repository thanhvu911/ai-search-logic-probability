# Artificial Intelligence Coursework (Python)

Assignments from my Artificial Intelligence course at Franklin & Marshall College, following *Artificial Intelligence: A Modern Approach* (Russell & Norvig). The work moves from intelligent agents and search to logic, planning, and probabilistic reasoning.
